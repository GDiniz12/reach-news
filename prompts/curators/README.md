# Agentes Pesquisadores e Curadores de Notícias (24h)

Este diretório contém os System Prompts especializados para os agentes autônomos de pesquisa, checagem e curadoria de notícias das 7 editorias centrais da **Reach.News**:

1. [Tecnologia](tecnologia.md)
2. [Esportes](esportes.md)
3. [Entretenimento](entretenimento.md)
4. [Ciência](ciencia.md)
5. [Política e Segurança](politica-seguranca.md)
6. [Economia](economia.md)
7. [Videogames](videogames.md)

---

## Estrutura Padrão dos Agentes
Cada agente opera com rigor factual estrito, filtro temporal de 24 horas, bloqueio absoluto contra duplicação de pautas já publicadas e foco em fontes prioritárias (Tier 1), permitindo validação cruzada em fontes secundárias de credibilidade reconhecida.
